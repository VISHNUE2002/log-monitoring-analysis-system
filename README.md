# Log Monitoring & Analysis System

A Python 3 tool designed to monitor and analyze application log files, detect suspicious security anomalies, and export structured JSON reports.

## Features

- **Regex Log Parsing**: Extracts timestamp, log level, IP address, and log messages.
- **Classification**: Categorizes logs into `INFO`, `WARNING`, and `ERROR`.
- **IP Error Aggregation**: Calculates error counts generated by each IP address.
- **Security Anomaly Detection**:
  - Flags repeated failed login attempts from offending IPs.
  - Implements a sliding window algorithm to detect bursts (> 10 errors within a 5-minute window).
- **Graceful Error Handling**: Skips malformed or corrupt lines without terminating.
- **Large File Optimization**: Streams logs line-by-line using Python generators for minimal memory usage.
- **Dynamic Configuration**: Thresholds are loaded dynamically from `config.json`.
- **CLI Support**: Flexible command-line arguments supporting single and multiple log files.
- **Zero External Dependencies**: Pure Python standard library (`re`, `datetime`, `collections`, `json`, `argparse`).

## Requirements

- Python 3.8 or higher (No third-party packages needed).

## How to Run

### 1. Default Run
Processes `sample.log` and exports results to `output_report.json`:
```bash
python src/main.py
```

### 2. Custom Input and Output
```bash
python src/main.py --input sample.log --output report.json
```

### 3. Multiple Log Files (Bonus)
```bash
python src/main.py --input server1.log server2.log --output combined_report.json
```

### 4. Custom Configuration File (Bonus)
```bash
python src/main.py --config config.json
```

---

## Configuration (`config.json`)

Thresholds are decoupled from the codebase:

```json
{
  "log_levels": ["INFO", "WARNING", "ERROR"],
  "security_threshold": {
    "failed_login_threshold": 3,
    "error_burst_window_minutes": 5,
    "error_burst_threshold": 10
  },
  "default_input_file": "sample.log",
  "default_output_file": "output_report.json"
}
```

---

## Output Report Structure (`output_report.json`)

The generated report contains:
- **`metadata`**: Timestamp of generation, source files analyzed, system status.
- **`processing_stats`**: Valid entries, offending IPs count, alerts triggered count.
- **`log_level_distribution`**: Total counts for INFO, WARNING, ERROR.
- **`errors_by_ip`**: Breakdown of errors per IP address.
- **`security_alerts`**: Structured list of detected security incidents with severity ratings.
